# Switch

<p class="docs-lead">Turn a setting on or off, applied at once.</p>

## When to use it

For a setting that takes effect the moment it is flipped, with no Save button: show hidden files, sync over mobile data.

- An option that waits for the form's Save, or rows to pick: use a [checkbox](../checkbox/).
- One choice out of several: use a [radio group](../radio/) or a [segmented control](../segmented-control/).

## With a label

The whole label is the target, as for the checkbox. A long label wraps; the switch stays on the first line.

<Demo html={`
<label class="b-check">
  <input class="b-switch" type="checkbox" role="switch" checked />
  <span>Sync over mobile data (large files wait for Wi-Fi)</span>
</label>
`} />

## Alone

Without a visible label, the switch needs `aria-label`.

<Demo html={`
<input class="b-switch" type="checkbox" role="switch" aria-label="Share Report.pdf" />
<input class="b-switch" type="checkbox" role="switch" aria-label="Share Budget.xlsx" checked />
`} />

## In Preact

```tsx
import { Switch } from '@beastui/preact';

<Switch checked={showHidden} onChange={setShowHidden}>
  Show hidden files
</Switch>
```

| Prop | Type | Default | |
|---|---|---|---|
| `checked` | `boolean` | required | The component is controlled. |
| `onChange` | `(checked: boolean) => void` | required | Apply the setting here, at once. |
| `children` | `ComponentChildren` | | The label. Without it, `aria-label` is required. |
| `class` | `string` | | Extra classes, on the label (or the switch when alone). |

## The CSS contract

| Markup | Effect |
|---|---|
| `<input class="b-switch" type="checkbox" role="switch">` | The 28 × 16 track and its thumb. |
| `<label class="b-check">` around the switch and a `<span>` | The label row, 8px from the switch. |
| `checked` | An ink track, the thumb at the far end (the start, right to left). |
| `disabled` | The switch (and its label) fade. |

## Accessibility

- A native checkbox: Space flips it, and the form sends it like any checkbox.
- `role="switch"` makes a screen reader say "on" and "off" ([APG, Switch](https://www.w3.org/WAI/ARIA/apg/patterns/switch/)).
- On is an ink track **and** the thumb's place, never colour alone.

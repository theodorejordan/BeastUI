# Skeleton

<p class="docs-lead">The shape of content that is on its way. The page keeps its layout while it loads, so nothing jumps when the content lands.</p>

Wrap sample text, about as long as the real one. The text turns invisible and gives the shape its size, so the real content takes the same room.

<Demo html={`
<p aria-busy="true">
  <span class="b-skeleton" aria-hidden="true">Budget 2027.xlsx was shared with the Finance team on Monday.</span>
</p>
`} />

## When to use it

The user waits, and the region has nothing to show yet: a table on first load, a profile, a list of files.

- The region already has content, and a job runs on it: use a [veil](../veil/).
- A job with a known length: use a [progress bar](../progress/).
- The load ended with nothing: use an [empty state](../empty/).

## Examples

### Lines

Empty, a skeleton is one line of text, as wide as its container. Give each line a width: real paragraphs never end at the same place.

<Demo html={`
<div aria-busy="true">
  <div class="b-skeleton" aria-hidden="true"></div>
  <div class="b-skeleton" aria-hidden="true"></div>
  <div class="b-skeleton" aria-hidden="true" style="inline-size: 60%"></div>
</div>
`} />

### Shapes

`data-shape="circle"` for an avatar, 32px unless you set a width. `data-shape="block"` for a picture or a chart: set its height.

<Demo html={`
<div aria-busy="true" style="display: flex; gap: 12px; align-items: center">
  <div class="b-skeleton" data-shape="circle" aria-hidden="true"></div>
  <div style="flex: 1">
    <div class="b-skeleton" aria-hidden="true" style="inline-size: 40%"></div>
    <div class="b-skeleton" aria-hidden="true" style="inline-size: 70%"></div>
  </div>
</div>
<div class="b-skeleton" data-shape="block" aria-hidden="true" style="block-size: 96px; margin-block-start: 16px"></div>
`} />

### In a table

Keep the header: the user sees what is coming. Sample text in each cell gives the rows their real height and the columns their real width.

<Demo html={`
<table class="b-table" aria-busy="true">
  <thead><tr><th data-grow>Name</th><th>Owner</th><th data-align="end">Size</th></tr></thead>
  <tbody aria-hidden="true">
    <tr><td><span class="b-skeleton">Budget 2027.xlsx</span></td><td><span class="b-skeleton">Ana Ruiz</span></td><td data-align="end"><span class="b-skeleton">24 KB</span></td></tr>
    <tr><td><span class="b-skeleton">Contract.pdf</span></td><td><span class="b-skeleton">Sam Lee</span></td><td data-align="end"><span class="b-skeleton">1.2 MB</span></td></tr>
    <tr><td><span class="b-skeleton">Brand guidelines.pdf</span></td><td><span class="b-skeleton">Ana Ruiz</span></td><td data-align="end"><span class="b-skeleton">8 MB</span></td></tr>
  </tbody>
</table>
`} />

### A beat late

`data-delay` keeps the skeleton hidden for one motion step (160ms). Content that arrives at once never flashes grey first. The room stays reserved meanwhile: nothing jumps.

<Demo html={`
<div aria-busy="true">
  <div class="b-skeleton" data-delay aria-hidden="true"></div>
  <div class="b-skeleton" data-delay aria-hidden="true" style="inline-size: 60%"></div>
</div>
`} />

## How it behaves

The tint pulses from light to dark grey, under a second each way: lively, but in place. Not a sweeping shimmer: a moving gradient pulls the eye across the page. The pulse follows the theme's tempo. With reduced motion, the shape stays still.

## Accessibility

A skeleton has nothing to read. Put `aria-busy="true"` on the region that loads and `aria-hidden="true"` on the shapes (or on the part that holds them): a screen reader then knows the region is loading, and does not read sample text. Remove `aria-busy` when the content is in ([MDN, aria-busy](https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Reference/Attributes/aria-busy)).

## In HTML

| Markup | Effect |
|---|---|
| `<span class="b-skeleton">Sample text</span>` | A tint the size of the text; the text is invisible. |
| `<div class="b-skeleton"></div>` | One line of text, as wide as its container. Set `inline-size` for less. |
| `data-shape="circle"` | A circle, 32px unless you set `inline-size`. |
| `data-shape="block"` | A box, radius 2. Set `block-size`. |
| `data-delay` | Hidden for one motion step, room kept. |

No Preact component: there is no behaviour to add. Write the markup, or wrap it in your own component.

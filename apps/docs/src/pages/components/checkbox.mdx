# Checkbox

<p class="docs-lead">Turn one option on or off, or pick several items from a list.</p>

## When to use it

For an option that takes effect when the form is saved, or to select rows.

- One choice out of several: use a segmented control or radios.
- A setting that applies at once: a switch (coming in a later batch).

## In Preact

```tsx
import { Checkbox } from '@beastui/preact';

<Checkbox checked={turnDown} onChange={setTurnDown}>
  Turn louder tracks down to the target
</Checkbox>

// "Select all" over a list:
<Checkbox
  aria-label="Select all tracks"
  checked={picked.size === tracks.length}
  indeterminate={picked.size > 0 && picked.size < tracks.length}
  onChange={(all) => setPicked(new Set(all ? tracks : []))}
/>
```

| Prop | Type | Default | |
|---|---|---|---|
| `checked` | `boolean` | required | The component is controlled. |
| `onChange` | `(checked: boolean) => void` | required | The new state. |
| `indeterminate` | `boolean` | `false` | Some but not all: shows a dash. |
| `children` | `ComponentChildren` | | The label. Without it, `aria-label` is required. |
| `class` | `string` | | Extra classes, on the label (or the box when alone). |

## The CSS contract

| Markup | Effect |
|---|---|
| `<input class="b-checkbox" type="checkbox">` | The 16px box. |
| `<label class="b-check">` around the box and a `<span>` | The label row, 8px from the box. |
| `checked` / `:indeterminate` | An ink box with a tick / a dash. |
| `disabled` | The box (and its label) fade. |

## Accessibility

- A native checkbox: Space toggles it, and a screen reader says "checked", "not checked" or "mixed".
- The mixed state is the `indeterminate` property ([MDN](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/input/checkbox#indeterminate_state_checkboxes)). It has no HTML attribute, so the CSS-only path can't set it: use the Preact component or one line of script.
- On is a filled box **and** a mark, never colour alone.

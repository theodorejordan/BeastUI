# Popover

<p class="docs-lead">A floating box with any content, opened by a button: a small filter, a detail, a short form.</p>

## When to use it

For a few controls that belong to one button and are not worth a place on the page.

- A list of actions: use a menu.
- A short text on hover, with nothing to click: use a tooltip.
- The user must answer before going on, or the content is long: use a modal.

## How it behaves

- A click on the button opens it under the button, lined up with its start edge. It goes above when there is no room below.
- Focus stays on the button. Tab goes into the box, then on to the rest of the page: the box comes right after the button.
- A click outside or Escape closes it. With focus inside, focus goes back to the button.
- The page stays usable while it is open: it is not a modal.

## In Preact

```tsx
import { Button, Popover } from '@beastui/preact';

const [open, setOpen] = useState(false);

<Popover trigger={<Button>Filter</Button>} label="Filter files" open={open} onOpenChange={setOpen}>
  …checkboxes…
  <Button variant="primary" onClick={() => { apply(); setOpen(false); }}>Apply</Button>
</Popover>
```

Without `open`, the button alone opens and closes it. Control it when something inside closes it, like Apply above.

| Prop | Type | Default | |
|---|---|---|---|
| `trigger` | one element | required | The button. It gets the ARIA attributes; its own handlers still run. |
| `children` | `ComponentChildren` | required | The content. |
| `label` | `string` | the button's name | Names the box for a screen reader. |
| `side` | `'bottom' \| 'top'` | `'bottom'` | The preferred side. It flips when there is no room. |
| `align` | `'start' \| 'end' \| 'center'` | `'start'` | Which edge of the button it lines up with. |
| `open` | `boolean` | | Controlled: open or closed. |
| `onOpenChange` | `(open) => void` | | Called when it opens or closes, however that happened. |


## Accessibility

- The box is a non-modal dialog (`role="dialog"`), named by `label` or by its button.
- The button says whether it is open (`aria-expanded`) and which box it opens (`aria-controls`).
- Keep the content short. Anything that needs scrolling belongs in a modal or a drawer.

## Without Preact

```html
<button class="b-btn" aria-expanded="false" aria-controls="p-1" popovertarget="p-1">Filter</button>
<div class="b-popover" id="p-1" role="dialog" aria-label="Filter files" popover="auto">…</div>
```

`popovertarget` and `popover="auto"` open and close it with no script. Placing it and `aria-expanded` are yours to write; the Preact component does both.

Tooltip: a short line that names or describes a control, on hover and keyboard focus. An ink box in the top layer (`popover="manual"`), so no overflow clips it. CSS `.b-tooltip`, Preact `Tooltip` (`content`, `mode` = description or label, `side`): hover delay with skip delay, hoverable, Escape closes the tooltip and not the modal around it, flips when there is no room.
